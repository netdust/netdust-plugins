## Summary

Two small deterministic scripts + thin emission hooks, following the loop pattern exactly (checker + hook, no daemon, no new gates): `spec-kit/run-trace.py` appends structured events to a per-feature `specs/<feature>/run-log.jsonl` (the in-loop trace); `spec-kit/run-score.py` compiles that log + `tasks.md` + `gate-check.py --json` into `specs/<feature>/run-rubric.md` with letter grades from documented thresholds (the evaluator rubric). `loop-gate.py` emits its decisions automatically (fail-open); the spines' prose names the controller emission points; `/shakeout` surfaces the rubric at spec-close. Report-only throughout — nothing new blocks.

Gate 1g (acceptance-flows matrix): N/A — no user-facing surface (CLI + file artifacts, no view/form/flow a human drives); the behavioral contracts live in the spec's acceptance criteria and their Tier-A tests, and the end-to-end flow is exercised by this feature's own dogfood run (it is the Phase-3 loop-eval target — the first armed run both tests and populates the trace).
